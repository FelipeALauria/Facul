Projeto Absolute Cinema

---

## Descrição
Este projeto é uma aplicação Java que utiliza JavaFX para a interface gráfica e o conector MySQL Java para acessar um banco de dados MySQL local.

## Bibliotecas Externas
- [JavaFX](https://openjfx.io/): Framework para desenvolvimento de interfaces gráficas em Java.
- [MySQL Java Connector](https://dev.mysql.com/downloads/connector/j/): Conector Java para comunicação com bancos de dados MySQL.

## Configurações Necessárias
1. **Instalação do Java**: Certifique-se de ter o Java Development Kit (JDK) instalado em sua máquina. Você pode baixá-lo em [java.com](https://www.java.com/).
2. **Configuração do JavaFX**: Se você estiver utilizando um ambiente de desenvolvimento como o IntelliJ IDEA ou Eclipse, configure o JavaFX no seu projeto. Consulte a documentação do seu IDE para obter instruções específicas.
3. **Adicionar o Conector MySQL ao Projeto**: Faça o download do MySQL Java Connector e adicione-o ao seu projeto como uma biblioteca externa.
4. **Configuração do Banco de Dados**: Se você estiver utilizando um banco de dados MySQL local, certifique-se de tê-lo instalado e configurado em sua máquina.

## Executando o Projeto
### A partir do Código-fonte
1. Clone o repositório do projeto ou baixe o código-fonte.
2. Abra o projeto em seu ambiente de desenvolvimento.
3. Certifique-se de que todas as dependências estejam corretamente configuradas.
4. Execute o projeto a partir do seu ambiente de desenvolvimento.

### Usando um Arquivo JAR
1. Certifique-se de que o projeto esteja construído e que o arquivo JAR esteja gerado.
2. Abra o terminal ou prompt de comando.
3. Navegue até o diretório onde o arquivo JAR está localizado.
4. Execute o seguinte comando para iniciar o projeto:

```bash
java -jar AbsoluteCinema.jar
