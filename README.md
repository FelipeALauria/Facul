# Facul

Repositório onde guardo o material da minha graduação em **Ciência da Computação na UNESP**: anotações, slides, listas de exercícios, provas antigas, trabalhos e códigos feitos em aula.

## Organização

Os arquivos estão separados por **ano** e, dentro dele, por **semestre**, e dentro de cada semestre por **disciplina**:

```
<ano>/<semestre>/<disciplina>/...
```

Disciplinas por período:

- **2023** — ATP 2, Circuitos Digitais
- **2024/1** — Álgebra Linear, Arquitetura de Computadores, Estrutura de Dados 1, Linguagem de Programação, Programação Orinetada a Objeto
- **2024/2** — Cálculo Numérico, Estrutura de Dados 2, Laboratório de Linguagem de Montagem, Probabilidade e Estatística, Projeto e Análise de Algoritmo
- **2025/1** — Banco de Dados, Engenharia de Software, Grafos, Redes, Sistema Operacional
- **2025/2** — Compiladores, Computação Gráfica e Programação Concorrente e Paralela
- **2026/1** — IA, Processamento Digital de Imagens, Sistemas Distribuidos

Cada pasta de disciplina normalmente contém uma mistura de: slides/PDFs de aula, listas de exercícios, provas antigas, resumos e os trabalhos/projetos com seus respectivos códigos.

## Aviso

Esse material é de uso pessoal, para estudo e consulta. Provas e trabalhos antigos podem não refletir o conteúdo/formato atual das disciplinas.
